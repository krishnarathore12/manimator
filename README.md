# Manimator

![Manimator Logo](./frontend/manimator/public/logo.svg)

Manimator is a web application that uses AI agents to generate and edit Manim animations from natural language queries. It allows users to create Manim videos withoutwriting Manim code directly, by leveraging Large Language Models to understand instructions and generate the corresponding Manim Python scripts.

## Features

*   **Natural Language Animation Generation:** Describe the animation you want, and Manimator's AI agents will generate the Manim code for you.
*   **Iterative Refinement:** Modify existing animations by providing further instructions in natural language.
*   **Code Debugging:** If the AI generates code that has errors, a debugging agent attempts to fix it.
*   **Live Preview (Conceptual):** (Assuming the frontend allows viewing the video) View the generated Manim video output.
*   **Manim Code Display:** See the Manim Python script generated by the AI.

## Tech Stack

*   **Backend:**
    *   Python
    *   FastAPI (for the web server)
    *   Manim (for animation rendering)
    *   Langchain / AI Agents (core logic for code generation, debugging, and updates)
*   **Frontend:**
    *   TypeScript
    *   React
    *   Vite (build tool)
*   **Package Management:**
    *   uv (for Python backend)
    *   npm (for frontend)

## Getting Started

### Prerequisites

*   **Python:** Version 3.12 (as specified in `backend/.python-version`). You can use a tool like `pyenv` to manage Python versions.
*   **Node.js and npm:** For running the frontend. You can download them from [nodejs.org](https://nodejs.org/).
*   **Manim:** The core animation engine. Follow the installation guide on the [official Manim documentation](https://docs.manim.community/en/stable/installation/index.html). Ensure its dependencies (like FFmpeg, LaTeX) are also installed.
*   **uv:** Used for Python package management in the backend. Install it via `pip install uv`.

### Backend Setup

1.  **Navigate to the backend directory:**
    ```bash
    cd backend
    ```

2.  **Set up a Python virtual environment:**
    It's recommended to use the Python version specified in `.python-version` (3.12).
    ```bash
    python3.12 -m venv .venv
    source .venv/bin/activate
    ```
    *(On Windows, use `.venv\Scripts\activate`)*

3.  **Install dependencies using uv:**
    ```bash
    uv pip install -r requirements.txt
    ```

4.  **Set up environment variables:**
    Copy the example environment file and fill in your API keys:
    ```bash
    cp .env .env.local
    ```
    Then, edit `.env.local` with your actual API keys for services like Google (Vertex AI/Gemini), Groq, Mistral, Firecrawl, and Together AI. These are used by the AI agents.
    ```
    GOOGLE_API_KEY=your_google_api_key
    GROQ_API_KEY=your_groq_api_key
    MISTRAL_API_KEY=your_mistral_api_key
    FIRECRAWL_API_KEY=your_firecrawl_api_key
    TOGETHER_API_KEY=your_together_api_key
    GOOGLE_MODEL=gemini-1.5-pro-latest # Or your preferred model
    GROQ_MODEL=llama3-70b-8192 # Or your preferred model
    ```
    *Note: The specific models (`GOOGLE_MODEL`, `GROQ_MODEL`) might be configurable or have defaults in the application code.*

5.  **Run the backend server:**
    ```bash
    uvicorn main:app --reload
    ```
    The backend server will typically start on `http://127.0.0.1:8000`.

### Frontend Setup

1.  **Navigate to the frontend directory:**
    ```bash
    cd frontend/manimator
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```
    *(Or if you prefer yarn: `yarn install`)*

3.  **Run the frontend development server:**
    ```bash
    npm run dev
    ```
    *(Or if you prefer yarn: `yarn dev`)*
    The frontend will typically start on `http://localhost:5173` and should automatically open in your browser.

## Usage

1.  **Ensure both backend and frontend servers are running** as described in the setup instructions.
2.  **Open your web browser** and navigate to the frontend URL (typically `http://localhost:5173`).
3.  **Use the input field** to type a description of the Manim animation you want to create (e.g., "Create a scene with a blue circle that fades in, then transforms into a red square").
4.  **Submit your query.** The AI agents will process your request, generate Manim code, and render the animation.
5.  **View the generated video** and the corresponding Manim code displayed in the interface.
6.  **Refine the animation** by providing further instructions in the input field (e.g., "Now make the square rotate 90 degrees").
7.  The application will attempt to update the existing code and re-render the video. If errors occur, the debugger agent will try to fix them.
